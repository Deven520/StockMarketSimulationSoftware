# A股模拟交易软件 — 需求规格说明书（SRS）

| 项目 | 内容 |
|------|------|
| 产品名称 | A股模拟交易系统（暂定：StockSim） |
| 文档版本 | V1.8 |
| 目标用户 | 个人投资者 / 策略研究者（模拟盘） |
| 核心目标 | 在模拟环境中，基于股票池与「一股一策」自适应做 T，结合实时行情执行；AI 负责策略画像/边界，盘中规则引擎动态调整；沉淀成交、盈亏与决策日志 |

---

## 1. 背景与目标

构建一套面向 A 股的**模拟炒股软件**：用户维护股票池与做 T 策略，系统按实时（或准实时）行情自动执行模拟做 T；每日沉淀成交与盈亏；支持通过 Cursor AI 按提示词选股与根据历史数据迭代策略；并通过 Web 监控面板查看历史与盈亏。

**非目标（本期不做）**
- 真实券商下单、资金划转
- 融资融券 / 期权 / 期货
- 保证盈利或投资建议承诺

---

## 2. 术语

| 术语 | 说明 |
|------|------|
| 做 T | 在持仓基础上，当日高抛低吸，收盘尽量回到原持仓股数，赚取日内差价（模拟盘按规则撮合） |
| 股票池 | 用户关注并允许策略运行的股票集合 |
| 策略 / StrategyPolicy | 一股一策的做 T **画像与边界**（触发区间、仓位区间、时段偏好、风控上限等）；非盘中逐笔脚本 |
| 有效参数 / RuntimeOverrides | 盘中在 Policy 边界内按波动、量比、连亏等算出的临时参数，不写策略版本表 |
| 状态机做 T | 默认「先高抛 → 再低吸买回」；状态含 Idle / SoldHigh / BoughtLow / RiskHalt / SessionAvoid / ForceFlat；盘中按开盘路径分型切换剧本 |
| 路径分型 | 高开高走 / 高开低走 / 低开高走 / 低开低走：开盘假设→早盘确认→锁定；创业板指可确认/削弱/禁止新开 T |
| 模拟成交 | 按行情价 + 滑点/手续费模型生成的虚拟成交记录 |
| Cursor AI | 通过 Cursor Agent / API / 工作流接入；用于选股与生成/迭代策略画像（秒级路径不调用） |
| 策略运行状态 | 标的已绑定且策略启用，且当前为 A 股连续竞价时段 →「运行中」；否则「未运行」 |
| 每股资金池 | 入池股票默认初始/可用资金 20 万，做 T 买卖从此预算划转 |
| 日K下钻 | 在日 K 图或日期表点击某交易日，展示该日分时/分钟 K 线 |
| 交易类型 TradeStyle | 做T股（日内做 T）/ 趋势股（观察+低位建仓、不做 T）/ **次日预涨**（预选下一交易日偏多，池内单独分组，执行同趋势） |
| 预涨日 | 次日预涨成分的目标交易日（通常为入库时的下一交易日） |
| 预涨结果 | 预涨日收盘（≥15:00）后结算：相对昨收收益&gt;0 为成功，否则失败；池内展示 |
| 高低价综合得分 | 以高/低平均绝对偏差%相对容差（默认 5%）打 0–100 分，并映射优秀/良好/一般/较差 |
| 次日命中 | 次日预选：方向命中（次日收益&gt;0）与目标命中（次日收益≥预期收益%） |

## 3. 功能需求

### 3.1 实时监控与自适应策略做 T（核心）

**描述**  
系统持续监控股票池内标的行情。**一股一策**：每只成分绑定专属策略画像（Policy）。盘中由 Worker 在连续竞价时段按状态机 + 有效参数自动高抛低吸；AI 只负责生成/日更画像边界，不进入秒级热路径。

**功能点**
1. **一股一策**：入池同步创建默认策略（名称默认「股票名+策略」）并绑定；后台异步 AI 刷新优化参数；支持手动「AI 刷新」。
2. **策略分层**  
   - L3 AI Planner：入池 / 每晚约 22:00 / 手动刷新 → **统一写入 AI 队列异步执行**（页面不阻塞）；「AI 队列」页可查看排队/执行中/成功失败及入参出参；提示词纳入关联投资目标的预期收益与周期  
   - L2 Adaptive：盘中按波动、量比、连亏等在 min–max 内微调有效阈值与仓位  
   - L1 Execution：约每 3 秒评估；状态机默认先高抛后低吸；锚点默认 VWAP  
3. 行情：最新价、量能近似、涨跌停等；Worker 优先东财轻量报价（失败回退 Replay）；列表页轻量报价。
4. 做 T 约束：
   - **入池首日建底仓**：每股 20 万可用资金；按 Policy.`baseBuild` 与当日涨跌幅决定是否买入及手数；`AllowTFromDate`=下一交易日之前禁止做 T
   - 底仓不足时只允许建底仓，不可无序开仓；有底仓后优先「卖出腿 → 买回腿」
   - **每股 AvailableCash** 不足不可买入；单日次数/仓位比例受 Policy 限制
   - 涨跌停、avoid 时段、收盘前 forceFlat、日亏停、连亏暂停
5. 撮合：最新价/对手价 + 费用模型；委托/成交落库。
6. **决策可解释**：接近触发或产生信号时写决策日志（状态、偏离、有效参数、拒绝原因）。
7. 运行时状态可跨进程恢复（Idle/SoldHigh 等）。

**验收标准**
- 新股入池当日仅可能建底仓，下一交易日起才出现做 T 成交。
- 回放/实时行情下，高抛→低吸状态转移与费用可复现。
- 涨跌停/停牌/风控场景不产生违规成交。
- AI 失败时仍有默认可运行策略；秒级路径不依赖大模型可用性。

### 3.2 股票池管理（手动 + Cursor AI 选股）

**描述**  
站点使用**单一默认股票池**（无池列表主页）。手工添加支持代码或名称二选一与模糊联想；也可 AI 选股确认入库。列表首屏快开，行情异步刷新。

**功能点**
1. **手工添加**：
   - 股票代码与名称**填其一即可**；输入框模糊匹配（东方财富联想）点选补全
   - 可选交易类型：做T股 / 趋势股 / **次日预涨**（次日预涨自动标记预涨日=下一交易日）
   - CSV 导入（代码/名称列）；移除；标签
   - 入池：默认初始/可用资金 **20 万**；同步默认策略 + 异步 AI 刷新队列（趋势/次日预涨不做自动做 T）
2. **AI 目标选股**（已移除工作台「策略建议」）：
   - 用户输入：预期收益%、预期周期（天）、题材偏好、**选股类型**（做T / 趋势 / **次日上涨预选**）
   - **次日上涨预选**：周期视为 1 天；入队时注入热点新闻与下一交易日等市场上下文；预选下一交易日更可能上涨的个股
   - AI 先生成选股提示词，再据此生成建议股；用户勾选入库
   - 每日记录相对预期收益的**达成率**（组合收益/预期收益）
   - **次日预选另计命中率**：目标日收盘后用真源日K收盘 vs 入库基准价；方向命中（收益&gt;0）、目标命中（收益≥预期%）；详情展示等权次日收益
3. **成分表展示**：
   - 库内首屏：持仓、成本、今日盈亏、可用资金、专属策略名、运行状态、**类型徽章**、**预涨日**、**预涨结果**（收盘后成功/失败+收益%）
   - 类型筛选：全部 / 做T / 趋势 / 次日预涨；**刷新后记住上次筛选**（localStorage，按池）
   - 异步刷行情：最新价、涨跌幅、市值、**浮动盈亏金额与百分比**（`(最新−成本)/成本×100`，轻量报价）
4. **明细**：点击「明细」查看该股操作记录（成交/拒单）与持仓盈亏摘要。
5. 个股「行情」面板：日 K / 分时 / 资金流 / 估值；日 K 可下钻分时；高低价预测历史含直观误差与等级。
6. 权限：开放访问（无站点登录）。

**验收标准**
- 仅填代码或仅填名称可成功入池；联想可选中。
- 入池后立即有可运行默认策略；AI 异步完成后策略版本更新。
- 股票池页首屏不因拉全年 K 线而长时间阻塞。
- 开市且已绑启用做T策略时显示「运行中」；次日预涨可筛出并显示预涨日；预涨日收盘后显示成功/失败。
- 次日预选目标日收盘后可见方向/目标命中；筛选刷新不丢失。

### 3.3 成交 / 盈亏记录与 AI 策略更新

**描述**  
按日汇总成交与盈亏；一股一策由夜间任务结合 21 日行情、新闻、当日成交与**决策日志**迭代 Policy；AI 工作台仍支持人机确认的选股/策略建议。

**功能点**
1. 日终：池/股/策略维度成交与盈亏、胜率、费用等。
2. 数据留存：成交、日盈亏、策略版本、运行时状态、决策日志。
3. **一股一策 AI 更新**（自动）：
   - 输出 StrategyPolicy v2（triggers/sizing/risk/session/style/**path** 等边界）
   - **同时输出目标交易日最高价 / 最低价预测**（`forecast.predictedHigh` / `predictedLow`，含 `softBandMode=softPrefer`、`capHighByLimitPct`；预测高须贴近涨停/ATR 上沿）
   - 可选 `path.pathPriors`（四类开盘路径先验，仅加权假设）
   - **目标日规则**：交易日且刷新时刻 &lt; 09:30 → 预测**当日**；否则预测**下一交易日**
   - 写入新 `StrategyVersion`，不绕过风控硬约束
4. **高低价预测准确率**（每晚约 22:00，与策略夜更同批；漏跑可补跑）：
   - **仅用真源目标日日K**高低对账；未收盘（&lt;15:00）/无该日日K/模拟回退行情**不对账**（禁用 Board 昨高低冒充今日）
   - **展示口径**（行情页历史表）：绝对误差（元）高/低、相对误差%（高/低绝对偏差%平均）、区间覆盖、综合得分 + 等级（优秀/良好/一般/较差）
   - **综合得分**：容差默认 **5%**，`clamp(100 × (1 − 相对误差%/5), 0, 100)`；页脚汇总历史综合准确率、**历史命中率**、**历史平均误差%**、AI 分项；**ATR 仅对照展示、不进准确率榜**
   - 写入准确率历史表（含**预测股票**代码/名称、**预测提示词**）；展示层可按偏差重算以兼容旧容差落库
   - **运营优化**：硬钳制（涨跌停/ATR 带宽）、样本≥5 才偏差校准（单次 ≤±5%、用中位数）、AI⊕ATR 融合；|偏|≥30% 异常样本不计榜
   - 近 14 日内已 Evaluated 若日K一致但得分与新公式不一致则重写；Actual 与日K不一致时按日K**重算纠错**
   - 再按上述规则生成新预测（夜更通常已收盘 → 预测下一交易日）
5. **做T每日复盘**（约 15:30，仅 `TradeStyle=做T股`）：收盘后自动入队 AI 复盘；落库提示词与结构化结论（路径/好坏点/ForceFlat/预测/配对价差）；无成交且无买卖决策则跳过；个股页可查阅与手动重跑；**夜更须注入近几日复盘**以优化 Policy。
6. AI 工作台：目标选股（含次日预选）与达成率/次日命中；一股一策夜更仍自动写 Policy。
7. 防呆：AI 输出须可反序列化为 Policy；非法则失败/回退；缺预测时用 ATR 基线（不计准确率），禁止占位污染榜单。

**验收标准**
- 日终与明细对账一致。
- 策略变更有版本；决策日志可供复盘与夜更输入。
- 夜更后可见预测股票、目标日、偏差与准确率历史；做T股可见每日复盘记录。

- 秒级做 T 在 AI 不可用时仍可按当前 Policy 运行。

### 3.4 Web 监控面板

**描述**  
用户通过浏览器查看历史数据、实时/准实时状态与盈亏。

**功能点**
1. 总览：模拟总资产、当日盈亏、持仓、策略运行状态、行情连接状态。
2. 股票池视图：成分、持仓盈亏/%、可用资金、专属策略、运行状态、类型/预涨日与类型筛选（可记忆）；行情异步刷新；明细/行情入口。
3. 个股终端面板：分时/分K、日K、资金流向、估值、策略状态、高低预测与直观准确率历史。
4. 个股操作明细：成交与拒单时间线、持仓与浮动盈亏摘要。
5. 成交明细：筛选（日期、代码、策略、买卖方向）。
6. 盈亏分析：按日/周/月；池收益曲线可按做T/趋势/次日预涨筛选；日终结算触发。
7. 策略中心：当前参数、版本历史、绑定。
8. AI 选股 / 目标达成：目标表单（含选股类型）、候选勾选、达成率与次日命中列表与明细。
9. 访问：站点开放（无登录）；密钥仍不入库明文。

**验收标准**
- 主流桌面浏览器可用；核心指标与后台计算结果一致。
- 关键列表分页与筛选正确；大数据量下查询可接受（见非功能）。

## 4. 非功能需求

| 类别 | 要求 |
|------|------|
| 性能 | 单池 ≤ 200 只时，策略评估延迟目标 ≤ 1–3 秒（视行情源频率） |
| 可用性 | 行情中断可降级为暂停交易并告警；服务重启后策略状态可恢复；个股详情接口失败可回退模拟数据 |
| 准确性 | 费用与盈亏计算规则文档化，单元测试覆盖关键公式 |
| 可追溯 | 委托、成交、策略变更、AI 调用全链路日志 |
| 安全 | 密钥（行情、AI）不入库明文；最小权限 |
| 合规声明 | 显著标注「模拟交易，非实盘投资建议」；第三方行情需遵守数据源条款 |

## 5. 外部依赖（业务视角）

1. **A 股行情源**：个股详情默认东方财富公开接口；Worker 做 T 可用 CSV 回放；生产建议采购合法行情。
2. **Cursor AI**：选股与策略迭代的推理入口（文件交换 / 提示词模板、人工确认）。
3. **前端图表**：ECharts（日K/分时/分K）。
4. **成交通知**：股票池可对单股开启监控；策略成交后经 Worker 推送 Webhook（企微/飞书/钉钉）或 PushPlus 微信（配置 `Alerts`）。

---

## 6. 用户故事（摘要）

1. 作为用户，我配置底仓与做 T 策略后，系统能按行情自动模拟做 T。
2. 作为用户，我能手工或用提示词让 AI 帮我筛股票并确认入库，且能查阅分析说明。
3. 作为用户，我希望每天自动看到各池盈亏，并让 AI 基于数据提出策略改进；确认后可**新增策略**或更新版本。
4. 作为用户，我能在网页上查看历史成交与盈亏，并在股票池中查看个股行情详情与运行状态。
5. 作为用户，我点击日 K 某日后，能看到该日分时/分 K。

## 8. 风险与假设

- A 股实盘「做 T」受 T+1 约束，本系统在**模拟盘**中按产品规则实现（需在设置中明确：仅允许卖出已有底仓、买入部分当日可卖或不可卖等模式开关）。
- Cursor AI 输出不稳定，必须「人机确认」后方可改池/改策略。
- 行情延迟与缺失会导致做 T 偏差，需有质量监控。
- 东方财富等公开接口可能变更、限流；不可作为生产唯一依赖。
