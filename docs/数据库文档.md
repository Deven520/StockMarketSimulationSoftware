# StockSim 数据库文档

| 项目 | 内容 |
|------|------|
| 文档版本 | V1.0 |
| 更新日期 | 2026-11-11 |
| 适用库 | SQLite（调试 / 本地部署）为主；亦可切换 SQL Server |
| 模型入口 | `StockSim.Infrastructure.Persistence.StockSimDbContext` |
| 结构演进 | `EnsureCreated` + `DbInitializer` 补表/补列（无独立 Migration 流水线） |

> **维护约定**：凡新增/删除表、改字段或增减会写库的业务操作，须**同步更新本文档**（表结构 + 写库操作列表 + 文末变更记录）。

---

## 1. 库文件位置

| 场景 | 路径 | 说明 |
|------|------|------|
| VS / `dotnet run` 调试 | `src/StockSim.Web/stocksim.db` | `Data Source=stocksim.db`，相对 Web 项目目录 |
| Worker 调试 | 指向 Web 同库 | `src/StockSim.Worker/appsettings.json` → `..\StockSim.Web\stocksim.db` |
| 一键部署 | `publish/web/stocksim.db` | Web 与 Worker 共用绝对路径 |
| 部署备份 | `publish/stocksim.db.bak` | 发布保留/测试库覆盖前备份 |
| Git 共享测库 | `src/StockSim.Web/stocksim.db` | `.gitignore` 例外纳入；`-wal`/`-shm` 仍忽略 |

旁路文件 `stocksim.db-wal` / `stocksim.db-shm` 为 SQLite WAL，**勿提交**。

## 2. 公共字段约定

| 基类 | 字段 |
|------|------|
| `EntityBase` | `Id` (Guid PK), `CreationTime` |
| `AuditedEntity` | 另含 `CreatorUserId`, `LastModificationTime` |

SQLite 下金额/日期等多以 TEXT/数值亲和性存储；EF 映射精度见 `StockSimDbContext.OnModelCreating`。

## 3. 表结构总览（19 张）

### 3.1 股票池

#### `AppStockPools` ← `StockPool`
| 字段 | 说明 |
|------|------|
| Name | 池名 |
| Description | 描述 |
| IsActive | 是否启用 |

#### `AppStockPoolItems` ← `StockPoolItem`
| 字段 | 说明 |
|------|------|
| StockPoolId | 所属池 |
| Symbol / Name | 代码 / 名称 |
| Tags / Remark | 标签 / 备注 |
| Source | 来源（手工 / AI 等） |
| TradeStyle | 做T=`1` / 趋势=`2` / 次日预涨=`3` |
| PredictedRiseDate | 次日预涨目标日（仅 NextDayRise） |
| BoundStrategyId | 绑定专属策略 |
| StrategyGeneratedAt / StrategyUpdatedAt | 策略生成/更新时间 |
| InitialCash / AvailableCash | 每股初始/可用资金（默认 20 万） |
| AllowTFromDate | 允许自动做 T 起始日 |
| NotifyOnTrade | 成交通知开关 |

**索引**：唯一 `(StockPoolId, Symbol)`；`BoundStrategyId`。

---

### 3.2 策略

#### `AppStrategies` ← `StrategyDefinition`
Name, Description, IsEnabled, CurrentVersionId

#### `AppStrategyVersions` ← `StrategyVersion`
StrategyDefinitionId, VersionNumber, ParametersJson, ChangeNote, CreatedBy  
**索引**：唯一 `(StrategyDefinitionId, VersionNumber)`

#### `AppStrategyBindings` ← `StrategyBinding`
StrategyDefinitionId, StockPoolId?, Symbol?, Priority, IsEnabled

#### `AppStrategyRuntimeStates` ← `StrategyRuntimeStateRow`
Symbol, TradeDate, State, DayRealizedPnL, LastSellPrice, LastBuyPrice, …  
**索引**：唯一 `(Symbol, TradeDate)`

#### `AppStrategyDecisionLogs` ← `StrategyDecisionLog`
Symbol, TradeDate, DecidedAt, State, Action, LastPrice, AnchorPrice, DeviationPct, …  
**索引**：`(Symbol, TradeDate, DecidedAt)`

---

### 3.3 账户 / 交易 / 盈亏

#### `AppSimAccounts` ← `SimAccount`
Name, Cash, InitialCash, TradingMode

#### `AppPositions` ← `Position`
SimAccountId, Symbol, Name, BaseQuantity, Quantity, SellableQuantity, AvgCost  
**索引**：唯一 `(SimAccountId, Symbol)`

#### `AppOrders` ← `Order`
SimAccountId, StrategyDefinitionId?, StockPoolId?, Symbol, Side, Quantity, Price, Status, RejectReason, TradeDate, IsManual  
**索引**：`(TradeDate, Symbol)`

#### `AppTrades` ← `Trade`
OrderId, SimAccountId, StrategyDefinitionId?, StockPoolId?, Symbol, Side, Quantity, Price, Commission, StampTax, TransferFee, Slippage, TotalFee, Amount, TradeDate, TradedAt  
**索引**：`(TradeDate, Symbol)`；`(StockPoolId, TradeDate)`

#### `AppDailyPnLs` ← `DailyPnL`
TradeDate, Symbol?, RealizedPnL, Fees, WinRate, TradeCount, …  
**索引**：`(TradeDate, Symbol)`

---

### 3.4 AI / 投资目标

#### `AppAiJobs` ← `AiJob`
JobType, Status, Prompt, InputPayload, OutputPayload, AnalysisSummary, AnalysisStepsJson, ErrorMessage, CompletedAt

#### `AppAiSuggestions` ← `AiSuggestion`
AiJobId, PayloadJson, Symbol, Name, Reason, SelectionLogic, Risk, IsAccepted, ReviewedAt, ReviewedBy

#### `AppAiQueueItems` ← `AiQueueItem`
TaskType（GoalToPrompt / StockPick / StrategyRefresh）, Status, Title, CorrelationId, RelatedGoalId?, RelatedAiJobId?, RelatedPoolItemId?, Symbol, InputPayload, OutputPayload, ErrorMessage, StartedAt, CompletedAt, WorkerId  
**索引**：Status；CreationTime；CorrelationId

#### `AppInvestmentGoals` ← `InvestmentGoal`
ExpectedReturnPct, HorizonDays, ThemePreference, TradeStyle, GeneratedPrompt, PromptRationale, Status, StartDate, TargetEndDate, StockPickJobId  
**索引**：Status

#### `AppInvestmentGoalStocks` ← `InvestmentGoalStock`
InvestmentGoalId, Symbol, Name, PoolItemId?, SuggestionId?, BaselineCash, BaselinePrice  
次日对账：TargetTradeDate, ActualClose, NextDayReturnPct, DirectionHit, TargetHit, EvaluatedAt  
**索引**：唯一 `(InvestmentGoalId, Symbol)`

#### `AppGoalProgressDailies` ← `GoalProgressDaily`
InvestmentGoalId, TradeDate, PortfolioReturnPct, AchievementRate, TotalMarketValue, TotalBaseline, RealizedPnL, UnrealizedPnL, DayIndex, Notes  
**索引**：唯一 `(InvestmentGoalId, TradeDate)`

---

### 3.5 高低价预测

#### `AppPriceRangeForecasts` ← `PriceRangeForecast`
Symbol, Name, ForecastForDate, PredictedAt, PredictedHigh/Low, ActualHigh/Low  
High/LowDeviationPct, High/LowAccuracyPct, CombinedAccuracyPct, RangeHit, EvaluatedAt, Status  
Source（Ai / CalibratedAi / AtrBaseline / Placeholder）, CountsTowardAccuracy  
StrategyDefinitionId?, StrategyVersionId?, AiJobId?, Prompt, Notes  

**索引**：`(Symbol, ForecastForDate)`；`(Symbol, ForecastForDate, Source)`；`(Status, ForecastForDate)`

## 4. 概念关系

```
StockPool ──< StockPoolItem >── StrategyDefinition / Binding
                 │
SimAccount ──< Position / Order / Trade / DailyPnL
                 │
InvestmentGoal → AiQueue / AiJob → AiSuggestion
       └───────< InvestmentGoalStock (+ 可选入池)
       └───────< GoalProgressDaily

夜更/队列：StrategyVersion + PriceRangeForecast
盘中：StrategyRuntimeState + StrategyDecisionLog + 成交
```

## 5. 会修改数据库的操作

### 5.1 Web 用户操作

| 入口 | 动作 | 主要写入表 |
|------|------|------------|
| 股票池 · 添加 / CSV 导入 | 入池 | AppStockPoolItems、AppPositions、AppSimAccounts、AppAiQueueItems、AppStrategies / Versions / Bindings |
| 股票池 · 移除 | 删成分 | AppStockPoolItems |
| 股票池 · 成交通知 | 开关 | AppStockPoolItems.NotifyOnTrade |
| 股票池 · AI 刷新 / 全池刷新 | 入队 | AppAiQueueItems |
| 行情 · 删除预测 | 删除 | AppPriceRangeForecasts |
| 策略中心 · 创建 / 改参 / 绑定 / 启停 / 删除 | CRUD | AppStrategies、AppStrategyVersions、AppStrategyBindings |
| 成交 · 手工下单 | 撮合 | AppOrders、AppTrades、AppPositions、AppSimAccounts、AvailableCash |
| 成交 · 删除成交 / 清仓 | 删/改 | AppTrades / AppPositions |
| 盈亏 · 日终结算 / 删日盈亏 | 重算或删 | AppDailyPnLs |
| AI · 提交目标选股 | 建目标+队列 | AppInvestmentGoals、AppAiJobs、AppAiQueueItems |
| AI · 勾选入库 | 入池+入选 | AppStockPoolItems…、AppInvestmentGoalStocks、Goals 状态、AppGoalProgressDailies |
| AI · 刷新达成率 | 结算/次日对账 | AppGoalProgressDailies、AppInvestmentGoalStocks（命中字段） |
| AI · 审阅建议 / 删目标 / 删 Job / 删队列 | 更新或删 | AppAiSuggestions、Goals+Stocks+Progress、AppAiJobs、AppAiQueueItems |

### 5.2 Worker / 后台

| 作业 | 动作 | 主要写入表 |
|------|------|------------|
| StrategyWorker | 做 T / 趋势低位建仓 | Orders、Trades、Positions、Cash、RuntimeStates、DecisionLogs |
| DailySettlementWorker | 日终盈亏 + 目标进度 + 次日命中 | DailyPnLs、GoalProgress、GoalStocks 对账字段 |
| Nightly / AI 队列消费 | 策略画像、高低预测对账与新预测 | StrategyVersions、PoolItems 策略时间、PriceRangeForecasts、AiJobs/Queue、Goals |

### 5.3 启动与部署（文件/结构级）

| 操作 | 影响 |
|------|------|
| 启动 `DbInitializer` | EnsureCreated、补列/补表；可能 UPDATE 旧 TradeStyle/PredictedRiseDate |
| 一键部署 Keep / Reset | 保留或丢弃 `publish/web/stocksim.db` |
| 一键部署「测试库覆盖部署库」 | 用 `src/.../stocksim.db` 覆盖部署库（先 `.bak`） |
| Git 拉取共享测库 | 整文件替换 SQLite，非行级迁移 |

### 5.4 基本不写库

行情 Quotes / 个股详情与分时、看板只读、股票联想 Suggest、多数监控测试推送（仅读配置发 HTTP）。

## 6. 结构演进与补丁

启动时 `DbInitializer` 负责：

1. 基础库 `EnsureCreated`
2. 历史列补丁（如 PoolItem 资金/TradeStyle/PredictedRiseDate、AI 查阅字段等）
3. 后增表：`AppStrategyRuntimeStates`、`AppStrategyDecisionLogs`、`AppInvestmentGoals*`、`AppGoalProgressDailies`、`AppPriceRangeForecasts`、`AppAiQueueItems`

**改库流程建议**：

1. 改 Domain 实体 + `StockSimDbContext` 映射  
2. 在 `DbInitializer` 增加 SQLite（及必要时 SQL Server）列/表补丁  
3. **更新本文档**对应章节与变更记录  
4. 本地验证：新库与旧库升级两条路径
