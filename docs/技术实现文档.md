# A股模拟交易软件 — 技术实现文档

| 项目 | 内容 |
|------|------|
| 技术栈 | .NET 8 / ASP.NET Core MVC / EF Core（开放访问，无需登录；ABP 风格分层）/ 开源组件 |
| 架构风格 | 分层单体，Web + Worker，可插拔行情与 AI 适配器 |
| 文档版本 | V1.8 |

> **实现现状说明**：当前仓库为可运行骨架，采用 **ABP 风格分层**，Web **无需登录**；并非完整 Volo.Abp 模板。Hangfire / SignalR / AdminLTE 等为规划项，下表区分「已采用」与「规划」。**V1.2** 起策略为「AI 画像 + 盘中自适应状态机」。

## 1. 总体架构

```
┌─────────────────────────────────────────────────────────┐
│  Web：股票池（首屏库内 + 异步轻量行情）/ 明细 / AI 工作台  │
└───────────────────────────┬─────────────────────────────┘
                            │ Application Services / JSON
┌───────────────────────────▼─────────────────────────────┐
│  L3 AI Planner（入池异步 / 22:00 夜更）→ StrategyPolicy   │
│  L2 AdaptiveOverride（波动/量比/连亏）→ RuntimeOverrides │
│  L1 状态机评估 + 风控 + 撮合（每股 AvailableCash）         │
└───────┬─────────────────────────────┬───────────────────┘
        │                             │
┌───────▼────────┐          ┌─────────▼──────────┐
│ 行情适配器      │          │ Cursor AI 适配器    │
│ Replay / 东财   │          │ SDK / 文件交换      │
│ 轻量报价+缓存   │          │                     │
└───────┬────────┘          └─────────┬──────────┘
        │                             │
┌───────▼─────────────────────────────▼───────────────────┐
│  SQLite / SQL Server；Worker：Strategy / 夜更 / 日终     │
│  + AiStrategyRefreshHostedService（Web/Worker 均可托管） │
└─────────────────────────────────────────────────────────┘
```

**设计原则**
- 行情、撮合、AI 均通过接口隔离，便于替换供应商与模型。
- **AI 定边界，规则做执行**：秒级路径不调用大模型。
- 策略执行与 Web 读写分离；列表行情短时内存缓存。
- AI 工作台改池仍需确认；一股一策入池/夜更为自动写版本（仍受 Schema 校验与风控硬约束）。

**高低价预测对账（`PerStockStrategyService` + `NightlyStrategyRefreshWorker`）**
- 策略提示词注入关联/最新 Active 投资目标的 `expectedReturnPct`、`horizonDays`（及题材偏好）
- 目标日：`PriceForecastMetrics.ResolveForecastTargetDate` — 交易日且 &lt;15:00 → 当日，否则下一交易日
- 实际高低：`ResolveActualHighLowFromDailyBars` **只读日K**；`CanFinalizeForecast` 要求目标日已过或当日≥15:00；`StockDetailBundle.IsSimulated` 为真则整批跳过
- 来源：`ForecastSource` = Ai / CalibratedAi / AtrBaseline / Placeholder；**占位不落准确率表**；**ATR 基线对照不计入准确率榜**（`CountsTowardAccuracy=false`，页面仍展示 ATR 分项对照）
- 运营链路：`ApplyOperationalForecast` = AI →（样本≥5 且中位偏差显著时）偏差校准（单次调整 ≤±5%）→ 硬钳制（涨跌停近似 `limitCapPct` + ATR 带宽 [0.6,1.8]×ATR）→ 与 ATR 按近史准确率加权融合（低分更靠 ATR）
- 每次刷新额外写入 **ATR14 基线** 对照行；对账 |偏|≥30% 记为异常样本，仍 Evaluated 但不计入榜
- 低准确率（综合 &lt;40）下调 `aggression`；盘中做 T 对有效预测施加软边界（默认 `softPrefer`：偏离达标时不硬拦，仅缩仓；预测高按昨收/开盘 `capHighByLimitPct` 钳制）
- 候选：近 `EvaluationLookbackDays`（14）日的 Pending/Skipped/Evaluated；Actual 与日K不一致时重算
- 偏差：`(预测 - 实际) / 实际 × 100`（仍落库；校准用中位数而非均值）
- **相对误差%**：`(|高偏%| + |低偏%|) / 2`
- **综合得分**（`DefaultTolerancePct=5`）：`clamp(100 × (1 − 相对误差%/5), 0, 100)`；单边 `AccuracyPct` 仍按各自 |偏差%| 相对容差
- **等级**：≥80 优秀 / ≥60 良好 / ≥40 一般 / 其余较差（`PriceForecastMetrics.AccuracyGrade`）
- 展示另算绝对误差（元）；`RangeHit`：实际高低均落在预测区间内
- 历史汇总：计入行的综合得分平均、区间命中率、平均相对误差%、AI 分项；ATR 分项仅对照；展示层 `RescoreCombinedAccuracy` 兼容旧 1.5% 落库
- 平均值仅统计 `CountsTowardAccuracy=true`（不含 ATR / 异常样本）

- 类：`StrategyParameters`（`FromJson` 兼容 v1 扁平字段并迁移）。
- 盘中：`IntradayPathClassifier` → `PathPlaybookResolver`（含创业板指 399006 过滤）→ `AdaptiveOverrideService` → `RuntimeOverrides` → `ToEffective()`。

### 4.3 做 T 执行流程（L1）

1. `StrategyWorker`（默认间隔 3s）→ `StrategyEngineService.EvaluateOnceAsync`
1b. 无底仓 → `BuildingBase` 按 `baseBuild` 买入；未到 `AllowTFromDate` → 不做 T；到期且有底仓 → 状态机高抛低吸
2. 仅 `AShareMarketSession.IsContinuousAuction` 时继续
3. 缓存 `399006` 涨跌幅；`GetLastAsync` → `IntradaySessionTracker`（开盘/VWAP/日高低/缺口/回撤）
4. `IntradayPathClassifier` 假设→确认→锁定；剧本路由后 `AdaptiveOverrideService.Adjust`
5. `IntradayTStrategyEvaluator.Evaluate(EvaluateContext)` 状态机 → `TradeSignal`（破 avoid / 冲高回撤卖 / softPrefer 缩仓）
6. `IRiskChecker`（含每股 `cashBudget`）→ `IMatchingEngine.PlaceAndFill`；维护 `OpenTQty`
7. 更新 `AvailableCash`、写 Order/Trade、决策日志、运行时状态（含 PathRegime/OpenTQty）
8. 日终 `PnLAppService.Settle`

**路径剧本**：HighOpenLowGo 正 T（可破 avoid）；HighOpenHighGo 慎卖/momentum；LowOpenHighGo 倒 T（启用回撤卖、卖阈值略松）；LowOpenLowGo defensive/BlockNewT。

**状态机摘要**：`BuildingBase` → `Idle` 优先高抛 → `SoldHigh` 低吸；`BoughtLow`（momentum，可回撤卖）；`SessionAvoid`（可破）；`ForceFlat`（先平 `OpenTQty`；超配减仓 `CountsTowardOpenT=false`，禁止卖后再买回）；`RiskHalt`。

**11-13 复盘优化**：预测低跌破≥3% → 软边界放行低吸 + Overrides 放宽买/收紧卖；大跌日缩仓；买入预留 `MinCashReserve`。

### 4.4 开市与运行状态

- 连续竞价：工作日 09:30–11:30 / 13:00–15:00。
- 池行「运行中」= 已绑启用策略 **且** 连续竞价中。

## 7. Cursor AI 接入

### 7.1 能力
1. **目标选股（工作台）**：预期收益% + 周期天 + 题材 + **选股类型** → `RunGoalToPrompt` → `RunStockPick` → 勾选入库 → `InvestmentGoal` 跟踪  
2. **次日上涨预选（`NextDayRise`）**：`horizonDays=1`；Goal 入参附 `marketContext`（热点新闻、`nextTradingDay`）；入库保留池类型并写 `PredictedRiseDate`  
3. **策略画像（一股一策，非工作台）**：近 21 日 K + 新闻 + 成交 + 决策日志 → StrategyPolicy v2  
4. ~~工作台策略建议~~：**已移除**（历史 `StrategyUpdate` 任务仍可读）  

### 7.2 实现
- `InvestmentGoalAppService`：两段 AI、入选、`SettleGoalAsync` 每日达成率；`EvaluateNextDayPicksAsync` 次日命中（`NextDayPickMetrics`）  
- `DailySettlementWorker` 日终结算目标进度 + 次日对账（含已完成的次日目标补算）  
- `CursorSdkAiClient` / `FileCursorAiClient`：`RunGoalToPromptAsync`（含 NextDayRise 分支）  
- `PerStockStrategyService` + 夜更 Worker 不变  

### 7.3 相关表
`AppInvestmentGoals` / `AppInvestmentGoalStocks`（含 `TargetTradeDate`/`ActualClose`/`NextDayReturnPct`/`DirectionHit`/`TargetHit`） / `AppGoalProgressDailies` / `AppStockPoolItems.PredictedRiseDate`  

### 7.4 AI 任务状态机（选股）
`Created → Running → SucceededPendingReview → Accepted/Rejected/Failed`

### 7.5 次日命中口径
- 基准价：入库时轻量报价 Last；目标日：下一交易日  
- 收益%：`(目标日收盘 − 基准) / 基准 × 100`（真源日K，模拟行情跳过）  
- 方向命中：收益 &gt; 0；目标命中：收益 ≥ 目标 `ExpectedReturnPct`  
- 汇总：方向/目标命中率、等权次日收益平均
