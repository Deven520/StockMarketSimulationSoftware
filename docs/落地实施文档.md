## 1. 落地目标与成功标准

### 1.1 本期落地目标
在本地/内网环境交付可运行的 **A 股模拟做 T 系统**：单一股票池、一股一策自适应做 T、每股资金预算、Cursor AI 辅助选股与策略画像、Web 监控（含轻量行情与操作明细）、个股行情详情与日K下钻。

### 1.2 成功标准（Definition of Done · 产品级）
1. 用户可直接打开 Web（无需登录）；代码或名称即可入池（含模糊联想）。
2. 入池即有默认可运行策略；AI 后台异步优化；开市 Worker 按状态机高抛低吸。
3. 股票池首屏快开，行情异步刷新；可查看持仓盈亏/%、类型/预涨日与可记忆筛选。
4. 日终盈亏可对账；决策日志与策略版本可追溯；高低价预测与次日预选命中可复盘。
5. AI 选股工作台支持做T/趋势/次日预选，可查阅并确认；密钥不入库明文。
6. 需求/技术/落地文档与 **V1.8** 实现一致；领域单测通过。

## 2. 范围冻结（防蔓延）

### 2.1 本期必做（P0）— V1.2 已覆盖
- 模拟账户 / 持仓 / 单一股票池（手工+联想+CSV）
- **一股一策** + 每股默认 **20 万** 可用资金
- **自适应策略引擎**（Policy v2 + Overrides + 状态机 + VWAP）+ Worker
- 模拟撮合 + 费用 + 决策日志 / 运行时状态表
- 日终结算与总览
- Cursor AI：选股工作台 + 入池/夜更策略画像
- 列表轻量行情（批量+缓存）+ 个股详情/日K下钻
- SQLite 开箱 / SQL Server；开放访问（无站点登录）

### 2.2 本期不做（明确砍掉）
- 真实券商柜台对接
- 融资融券 / 打新 / 科创板特别机制精细化（可预留扩展点）
- 保证收益；秒级路径直连大模型下单
- 移动端 App
- 完整 Volo.Abp / Hangfire / SignalR（列为后续）

### 2.3 决策清单（已拍板）
| 决策项 | 结论 |
|--------|------|
| 运行时 | **.NET 8** + ABP 风格分层（非完整 ABP 模板） |
| 做 T 规则 | 默认 `SimIntradaySellAllowed`；状态机先高抛后低吸；Policy 定边界 |
| 行情源 | Worker：**CSV 回放**；个股详情：**东方财富公开接口**（失败回退模拟） |
| AI 接入 | Cursor SDK + 文件占位；一股一策自动写版本；工作台选股仍人工确认 |
| 策略架构 | AI Policy 边界 + 盘中 Overrides + 状态机；秒级不调模型 |
| 列表行情 | 轻量批量报价 + 30s 缓存；首屏库内数据 |
| 部署形态 | **Web + Worker 双进程**（同库） |
| 图表 | **ECharts 5.5.1**（CDN） |

### 4.1 开发机
- Windows 10/11，Visual Studio 2022（或兼容 IDE）
- .NET SDK（按选型）
- SQL Server 2012+（LocalDB/Express/正式实例均可，注意兼容性验证）

## 5. 分阶段落地计划（建议 6–8 周）

> 可按人力压缩；原则是 **每阶段可演示、可回滚**。

### 阶段 M0：项目基线（3–5 天）
**产出**
- 解决方案与 ABP MVC 模板跑通
- SQL 库迁移成功（2012 验证）
- 登录/权限骨架、空 Dashboard
- 文档与分支策略（`main` / `develop`）

**验收**
- 能登录；Migrator 在 SQL 2012 实例执行无报错。

---

### 阶段 M1：账户 · 股票池 · 手工交易（1–1.5 周）
**产出**
- 模拟账户、持仓 CRUD
- 股票池手工维护 + CSV 导入
- 手工模拟下单 → 成交 → 持仓变化
- 基础成交列表页

**验收用例**
1. 添加 10 只股票入池。
2. 买入后资金与持仓正确；卖出受持仓约束。
3. 费用按配置扣减，明细可查。

**退出标准**
- 无策略也能完成「模拟买卖闭环」。

---

### 阶段 M2：策略做 T 引擎（1.5–2 周）
**产出**
- 策略定义 / 版本 / 绑定
- `StrategyEvalJob` + 内存报价（可先 Stub Provider）
- 风控：涨跌停、停牌、次数/仓位上限
- 委托状态与审计日志
- SignalR 推送委托/成交（可后置）

**验收用例**
1. 回放一段「先跌后涨」Tick，策略按阈值完成做 T 买卖。
2. 人为制造涨跌停报价，系统拒单并记原因。
3. 策略改参后生成新版本，旧版本可回滚。

**退出标准**
- 同一回放文件多次运行，成交结果一致（确定性）。

---

### 阶段 M3：日终盈亏 + Web 监控完善（1 周）
**产出**
- `DailySettlementJob`
- 池/策略/个股日盈亏表
- Dashboard：资产、当日盈亏、曲线（ECharts）
- 筛选分页成交与盈亏查询

**验收用例**
1. 日终任务后，汇总 = 明细加总。
2. 面板数字与 SQL 查询一致。
3. 连续多日回放，曲线与胜率指标正确。

---

### 阶段 M4：Cursor AI 闭环（1–1.5 周）
**产出**
- AI 选股：提示词 → 建议列表 → 用户确认入库 + 审计（含做T/趋势/**次日上涨预选**）
- 一股一策：入池默认策略 + 异步 AI；夜更 22:00 刷新 Policy v2 + 高低价预测对账（5% 容差直观得分）
- 次日预选：新闻上下文入队；目标日收盘后方向/目标命中
- AI 工作台页面与任务状态机

**验收用例**
1. 工作台未确认建议不改池。
2. 入池 AI 失败仍有默认可运行策略；Worker 做 T 不依赖 AI 在线。
3. 坏 JSON 任务失败可重试。
4. 次日预选入库后池内可见类型与预涨日；收盘后命中率可刷新。

---

### 阶段 M5：股票池 UX + 自适应策略（V1.2→V1.8）
**产出**
- 代码/名称二选一 + 模糊联想；每股 20 万；明细页；类型筛选记忆
- 列表首屏 + `/Pools/Quotes` 异步轻量行情（含浮动盈亏%）
- StrategyPolicy / 状态机 / VWAP / Overrides / 决策日志与运行时表

**验收用例**
1. 仅填名称或仅填代码可入池；列表秒开后刷出报价。
2. 回放「先涨后跌」：先卖后买回；决策日志有状态与偏离。
3. 旧扁平策略 JSON 可被 `FromJson` 迁移运行。

**退出标准**
- AI 模块故障时，做 T 与结算仍可独立运行。

---

### 阶段 M5：行情实接 · 硬化 · 交付（0.5–1 周）
**产出**
- 至少一个真实/准实时 MarketData Provider（或明确仅回放交付）
- 交易日历、节假日停跑
- 日志、Hangfire/作业监控、备份脚本
- 安装说明 + 验收报告

**验收**
- 按第 8 节清单走完签字。

## 9. 数据与对账规范（落地必守）

1. **成交主键**与**日盈亏**以数据库为准；面板只读聚合。
2. 每次策略变更必须写 `StrategyVersion`，禁止原地覆盖无历史。
3. AI 输入输出原文（可截断）落 `AiJob`，便于复盘「模型胡说」。
4. 回放测试使用固定种子文件，文件名含日期与品种列表。
5. 日终任务幂等：同一 `TradeDate` 重复执行结果一致。

## 10. 风险落地应对

| 风险 | 表现 | 应对 |
|------|------|------|
| 行情源不稳 | 漏 Tick、延迟 | Stub/Replay 保交付；Live 熔断暂停策略 |
| AI 输出非结构化 | 解析失败 | JSON Schema 校验 + 失败重试 + 人工编辑 |
| T+1 认知歧义 | 用户期望与规则不符 | 设置页明确模式；默认文案提示 |
| SQL 2012 限制 | JSON/高版本语法 | 应用层序列化；迁移脚本人工审查 |
| 范围膨胀 | 要接实盘 | 本手册 2.2 冻结，另立项 |

## 11. 发布与运维最小集

### 11.1 首次部署步骤

**本地一键（推荐，默认 SQLite）**

1. 安装 [.NET 8 SDK](https://dotnet.microsoft.com/download/dotnet/8.0)。
2. 双击 `scripts/一键部署.bat`，或执行 `.\scripts\deploy-local.ps1 -Start`。
3. 若已有 `publish/web/stocksim.db`，脚本会询问 **保留(K)** 或 **覆盖重建(R)**（回车默认保留）。也可非交互：`-KeepDatabase` / `-ResetDatabase`。
4. 若存在测试库 `src/StockSim.Web/stocksim.db`，脚本会再询问是否 **用测试库覆盖部署库 [Y/N]**（回车默认否）。覆盖前会备份到 `publish/stocksim.db.bak`。非交互：`-SeedFromTestDatabase` / `-SkipSeedFromTestDatabase`。
5. 浏览器打开 `http://localhost:5167`（无需登录）；核对总览 / 股票池 / Worker 日志。
6. 停止：`.\scripts\stop-local.ps1`。

发布产物在 `publish/web`、`publish/worker`，共用 `publish/web/stocksim.db`；完整发布前会备份到 `publish/stocksim.db.bak`；回放与 AI 目录指向仓库 `data/`。

**SQL Server / 手工部署**

1. 创建 SQL 库，执行 Migrator（或 `scripts/init-sqlserver.sql`）。
2. 配置 Web 与 Worker 的 `appsettings`/环境变量。
3. 导入交易日历与演示种子数据。
4. 启动 Web，创建管理员；启动 Worker。
5. 跑 `data/replay` 冒烟；打开 Dashboard 核对。
6. （可选）配置 AI 工作目录或 Endpoint，跑一条选股建议。

### 11.2 日常运维
- 每日检查：行情作业、策略作业、日终作业是否成功。
- 每周：库备份；磁盘与日志体积。
- 策略/AI 变更：仅管理员；重要变更双人复核（可选）。

### 11.3 回滚
- 应用：保留上一版本包。
- 策略：版本回滚功能。
- 数据：按备份还原（先停 Worker）。
